# 💜 Braiding By Me — Business Website

**Clean • Neat • Stylish**

## 1. Project Overview

Braiding By Me is a responsive website designed for a hair-braiding business. It allows customers to explore hairstyles, view service prices, and request appointments.

The project also includes a business productivity dashboard to help the owner manage appointments, organize daily tasks, track completed activities, and improve business efficiency.

The website features a calming purple and pink color scheme, a user-friendly interface, and light and dark display modes.

## 2. Features

- **Homepage:** Business introduction, branding, and featured hairstyles.
- **Services and Pricing:** Displays braiding styles and their prices in South African rand (ZAR).
- **Appointment Booking:** Allows customers to submit appointment requests.
- **Task Management:** Add, edit, delete, and mark tasks as completed.
- **Task Categories:** Organize tasks into appointments, hair preparation, supplies, marketing, finances, and personal tasks.
- **Task Priorities:** Assign high, medium, or low priority and set due dates.
- **Progress Tracking:** View completed, pending, and overdue tasks.
- **AI Productivity Assistant:** Supports planned AI-powered task planning, client message generation, and notes summarization.
- **Dark Mode:** Switch between light and dark themes.
- **Responsive Design:** Supports desktop, tablet, and mobile layouts.
- **WhatsApp Contact:** Provides a convenient way for customers to contact the business.

*Note: Features that depend on database storage, authentication, or AI integrations require appropriate configuration and testing.*

## 4. Setup Instructions

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- A GitHub account

### Step 1: Clone the repository

Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/braiding-by-me-website.git
```

### Step 2: Navigate to the project folder

```bash
cd braiding-by-me-website
```

### Step 3: Install dependencies

```bash
npm install
```

### Step 4: Start the development server

```bash
npm run dev
```

### Step 5: Open the website

Open the local development URL displayed in your terminal, usually:

```text
http://localhost:5173
```

The exact URL may differ depending on the project configuration.

### Configuration

If the project uses Supabase or an AI API, configure the required environment variables using the project's documentation and environment example file, if available.

**Security:** Never commit secret API keys, passwords, or private customer information to GitHub.
